# leaki-shorts-media

Public hosting for Leaki short-form videos with music, used as stable direct file URLs for scheduling (not a social post by itself).

Silent visual masters are kept separately and are not overwritten. These release assets are music versions mixed on November 10, 2026 (America/Chicago).

## License of the music

Each video uses a track downloaded from [Pixabay Music](https://pixabay.com/music/) with Pixabay's own Free download button, under the [Pixabay Content License](https://pixabay.com/service/license-summary/). That license allows commercial use inside a video. The MP3s are not redistributed here as standalone files.

Several tracks are marked Content ID Registered on Pixabay. A platform claim can still appear; it can usually be released with Pixabay's Content ID instructions.
